# /business-plan Command

## 사용법
```
/business-plan [사업 아이디어 또는 기존 계획]
/business-plan [내용] --purpose [investment|internal|competition]
```

## 예시
```
/business-plan "AI 기반 법률 검색 서비스"
/business-plan [기존 계획서 내용] --purpose investment
```

## 목적별 구성
- `investment` : 투자유치용, 시장규모·수익모델·팀 강조
- `internal` : 내부기획용, 실행계획·리소스·일정 중심
- `competition` : 공모전용, 혁신성·사회적 가치 강조

## 포함 항목
1. 사업 개요 (비전, 미션)
2. 문제 정의 및 솔루션
3. 시장 분석 (TAM/SAM/SOM)
4. 경쟁사 분석
5. 비즈니스 모델
6. Go-to-Market 전략
7. 팀 구성 (해당 시)
8. 로드맵 및 KPI

**주의:** 시장 규모 수치는 추정값입니다. 실제 조사를 통해 검증하세요.
