Command Center
Claude Code에서 바로 사용할 수 있는 8개의 슬래시 커맨드. 클릭하면 클립보드에 복사됩니다.
Command Skill 설명 예시
/research Research Assistant 주제를 체계적으로 조사하고 보고서를 생성 /research "AI 반도체 시장"
/analyze Data Analyst 데이터·코드·텍스트를 분석하여 인사이트 제공 /analyze [CSV 데이터]
/review Coding Assistant 코드·문서·계획을 검토하고 개선 의견 제공 /review [코드 블록]
/report Document Assistant 구조화된 보고서를 생성 /report "월간 성과" [데이터]
/business-plan Business Assistant 사업계획서를 구조화된 형식으로 작성 /business-plan "AI 법률 서비스"
/legal-research Legal Research 법령·판례 조사 및 법적 쟁점 정리 (정보 제공, 자문 아님) /legal-research "해고 요건"
/summarize Document Assistant 긴 문서를 핵심 중심으로 요약 /summarize [기사 내용]
/automate Automation Agent 반복 작업을 자동화하는 스크립트를 설계 /automate "매일 파일 백업"
MCP Integrations
Model Context Protocol을 통한 외부 서비스 연동. 실제 연동은 사용자가 직접 설정합니다.
ℹ️
아래 MCP 연동은 설정 가이드 제공 단계입니다. 실제 연동을 위해서는 .mcp.json.example을 복사하여 API Key를 설정하고 Claude Code에서 MCP 서버를 활성화해야 합니다.
